# Security policy

The latest stable HIT release receives security fixes. Verify the issue on that release or the current `master` branch if possible.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/hit-scm/hit/security/advisories/new). If that form is unavailable, contact a maintainer privately. Keep vulnerability details out of public issues and discussions until disclosure has been coordinated.

Include the affected version, platform, reproduction steps, and potential impact. Redact credentials and personal data. Maintainers will confirm receipt when they review the report and coordinate remediation and disclosure through the advisory.
