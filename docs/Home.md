# HIT documentation

HIT provides a command-line interface and a desktop app for working with Git repositories.

- [Installation](Installation.md) explains release downloads, checksums, and source builds.
- [Quickstart](Quickstart.md) walks through reviewing, committing, and pushing changes.
- [Commands](Commands.md) lists the CLI commands and examples.
- [Authentication](Authentication.md) covers Git hosts, SSH, HTTPS, and credentials.
- [Desktop](Desktop.md) covers the desktop workspace and local development.
- [Troubleshooting](Troubleshooting.md) helps diagnose repository and remote failures.
- [Development](Development.md) covers checks, benchmarking, and documentation publishing.

See the [project repository](https://github.com/hit-scm/hit) for releases, source code, and contribution policies.
